# Changelog

## 2026-11-12 — v1.0
- Generic version of the Netherlands jobs daily report: any country/locations, 2–5 directions, AI-chosen number of company tiers, all driven by a per-user `profile.json`.
- Onboarding: intake questionnaire (mostly multiple choice) + CV analysis (`references/intake-questionnaire.md`, `references/build-profile.md`).
- Visa sponsorship: none / official register (xlsx or csv) / research mode. Netherlands IND register (2026-10-05) bundled.
- Description filters generalised: max years of experience, fluent local-language requirement (configurable words per language).
- Report layout unchanged from the original: 今日概览 · 梯队 · 其他公司 · 个人背景 · 投递渠道; Chinese or English labels.
- Example profiles: Netherlands tech (reproduces the original report's company matching and filters exactly), Germany data (English, research mode).
